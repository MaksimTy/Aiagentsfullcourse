Описание модуля
================

Модуль :mod:`src.agent.budget` предоставляет класс :class:`Budget` для управления
ресурсами и лимитами выполнения агента. Класс реализует мониторинг и проверку
ограничений, предотвращая чрезмерные затраты ресурсов.

Назначение класса
=================

Класс :class:`Budget` служит для:

- **Отслеживания затрат**: следит за количеством шагов, токенов, времени и стоимости
- **Проверки лимитов**: проверяет, не превышены ли установленные ограничения
- **Уведомления о критических ресурсах**: генерирует мягкие предупреждения при близком
  достижении лимитов
- **Снапшотов состояния**: формирует сводку текущего состояния бюджета

Архитектурные принципы
======================

1. **Проверка до траты**: границы проверяются *до* начала нового шага выполнения
2. **Иммутабельность задачи**: объект :class:`Task`, передаваемый в бюджет, является неизменяемым
3. **Автоматический старт**: таймер начината отсчет при создании экземпляра

Пример использования
====================

Создание и использование бюджета::

    from src.agent.task import Task
    from src.agent.budget import Budget
    
    # Создание задачи с лимитами
    task = Task(
        prompt="Посчитай факториал 17",
        max_steps=10,
        max_cost_usd=0.50
    )
    
    # Создание бюджета
    budget = Budget(task=task)
    
    # Проверка превышения лимитов
    reason = budget.exceeded()
    if reason:
        print(f"Бюджет исчерпан: {reason}")
    
    # Получение мягкого предупреждения
    warning = budget.soft_warning()
    if warning:
        print(warning)
    
    # Снимок состояния
    snapshot = budget.snapshot()
    print(f"Шаги: {snapshot['steps']}")
    print(f"Стоимость: {snapshot['cost']}")
