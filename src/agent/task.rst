Описание модуля
================

Модуль :mod:`src.agent.task` предоставляет класс :class:`Task` для описания
задачи, которую агент должен выполнить. Класс представляет собой неизменяемый
(dатaclass с ``frozen=True``) контейнер для параметров задачи и её ограничений.

Назначение класса
=================

Класс :class:`Task` служит для:

- **Хранения инструкций**: хранит подсказку (prompt), которую агент получает от пользователя
- **Определения критериев успеха**: задаёт постусловие (postcondition) для проверки выполнения
- **Установки лимитов**: определяет максимальные значения для ключевых ресурсов
- **Конфигурации поведения**: позволяет настраивать поведение агента через параметры

Архитектурные особенности
===========================

**Иммутабельность**

Класс объявлен как ``@dataclass(frozen=True)``, что делает его неизменяемым.
Это гарантирует, что агент не может изменить задачу в процессе выполнения,
обеспечивая:

- Согласованность поведения агента
- Возможность безопасного кэширования и сериализации
- Предсказуемость при тестировании

**Атрибуты как параметры конфигурации**

Все атрибуты имеют значения по умолчанию, получаемые из переменных окружения,
что позволяет гибко настраивать поведение без изменения кода.

Метод проверки постусловий
===========================

Функция :func:`verify` использует атрибут ``postcondition`` для проверки выполнения задачи::

    from src.agent.task import Task
    
    def is_factorial_correct(answer: str) -> tuple[bool, str]:
        """Проверяет, что ответ содержит правильный результат факториала."""
        try:
            result = int(answer.strip())
            expected = 355687428096000  # 17!
            if result == expected:
                return True, "Результат верен"
            return False, f"Ожидалось {expected}, получено {result}"
        except ValueError:
            return False, "Ответ не является числом"
    
    task = Task(
        prompt="Посчитай 17 факториал",
        postcondition=is_factorial_correct
    )

Пример использования
====================

Создание задачи с лимитами::

    import os
    from src.agent.task import Task
    
    # Создание задачи с пользовательскими лимитами
    task = Task(
        prompt="Найди информацию о Python в файле README.md",
        max_steps=20,
        max_seconds=60.0,
        max_cost_usd=0.25
    )
    
    # Создание задачи с постусловием
    def verify_answer(answer: str) -> tuple[bool, str]:
        if "Python" in answer:
            return True, "Найдена информация о Python"
        return False, "Информация о Python не найдена"
    
    task = Task(
        prompt="Прочитай файл и найди упоминания Python",
        postcondition=verify_answer
    )

Использование с переменными окружения::

    # Установка через переменные окружения
    os.environ["AGENT_MAX_STEPS"] = "30"
    os.environ["AGENT_MAX_COST_USD"] = "1.00"
    
    # Задача будет использовать эти значения по умолчанию
    task = Task(prompt="Выполни сложную задачу")
    print(task.max_steps)    # 30
    print(task.max_cost_usd) # 1.00

Интеграция в систему агента::

    from src.agent import Task, Budget, Trace
    from src.agent.budget import Budget
    
    def run(task: Task, tools, llm, trace: Trace) -> dict:

Переменные окружения
=====================

.. envvar:: AGENT_MAX_STEPS

    Максимальное количество шагов выполнения. Значение по умолчанию: 16.

.. envvar:: AGENT_MAX_SECONDS

    Максимальное время выполнения в секундах. Значение по умолчанию: 300.

.. envvar:: AGENT_MAX_TOKENS

    Максимальное количество токенов. Значение по умолчанию: 200_000.

.. envvar:: AAGENT_MAX_COST_USD

    Максимальная стоимость выполнения в долларах США. Значение по умолчанию: 0.50.
